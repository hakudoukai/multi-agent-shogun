## §三 ①案の形 ―― ★一つの test に二つの役を負はせて居た★

**之が「直すと赤」の因である。**

現行の一枚は次の二役を同時に負つて居る ――

- **㋐ 見張り**（回帰の見張り）＝ 製品 code の今の姿を映し、姿が崩れたら赤に成る。
- **㋑ 印**（欠陥の姿の保存）＝ 何が現に間違つて居たか・何を直せば良いかを字で残す。

`xfail(strict=True)` は ㋑ を負ふ器である。而して製品が直ると XPASS で落ちる
∴ **㋐ の向きが逆に成る**（直した者が赤を踏む）。之が order200 で上へ回した材である。

### 案 ―― 二枚に割る（正の対照と 負の対照）

直した commit と ★同じ commit の中で★ 一枚を二枚にする。

| 名 | 何を見るか | 直つた後の色 | 欠陥が戻つた時の色 | 負ふ役 |
|---|---|---|---|---|
| **正の対照**（＝現行のマーカーを外した素の一枚） | ★製品 code★ | 通る | ★落ちる★ | ㋐ 見張り |
| **負の対照**（＝新設の一枚） | ★製品でなく 欠陥を再現した造り物★ | 通る | 通る（製品に依らぬ） | ㋑ 印 |

負の対照が表明するのは「製品が正しい事」ではなく、**「此の検めは 欠陥の姿に対して 現に落ちる」**事である。
∴ 検めが空回りして居らぬ事（＝検めが偽の通過を出す器でない事）を、直つた後も走る形で残す。

### 誰が・何時・何を見れば「直つた」と判るか

| 問 | 現行（`strict=True` 一枚） | 本案（二枚） |
|---|---|---|
| 誰が | 直しの commit を押した者（自分で赤を踏む） | 走らせる者（CI）と 讀む者の双方 |
| 何時 | 直した ★其の走★（XPASS で落ちる） | 直した ★其の走★（正の対照が赤から通るへ転ずる） |
| 何を見れば | 「スイートが落ちた事」＝ ★直つた事と壊れた事が 同じ色（赤）で出る★ | 正の対照 = 通る／負の対照 = 通る の ★二つが同時に立つ事★ |
| 直つて居らぬ時 | 落ちぬ（xfail） | 正の対照 = 落ちる／負の対照 = 通る |
| 検めが空回りして居る時 | ★見えぬ★ | 負の対照が ★落ちる★（＝検め其の物の疵が出る） |

∴ 本案では **色が三通りに割れる** ―― ⑴正×負○＝未だ直つて居らぬ ⑵正○負○＝直つた
⑶正○負★×★＝**検めが空回り**（造り物の欠陥すら捕へられぬ）。
現行の一枚では ⑵ と「壊れた」が同じ赤に潰れ、⑶ は現に見えぬ。
