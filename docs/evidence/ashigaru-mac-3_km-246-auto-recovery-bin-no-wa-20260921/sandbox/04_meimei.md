# ⑹㋓ 一言の名 ―― 己の便が己の引金に成る現象

**「自己言及的発火」(自らが書いた未読メッセージを、自らの後続周期が読み取って
自らの次の動作の発火条件に使う ―― 送り手と受け手と引金の三役を watcher 自身が兼ねる構造)。**

一行(英名併記): self-referential firing ―― 送信 (`enqueue_recovery_task_assigned`) と
判定 (`has_task_assigned`) と発火 (`send_context_reset`) が同一プロセス内の別周期に分かれて
実行される為、外部からの新規入力(agentの既読化)が無い限り、自分が書いた1通のメッセージが
無期限に自分自身の次の `/clear` の根拠として再利用され続ける。
