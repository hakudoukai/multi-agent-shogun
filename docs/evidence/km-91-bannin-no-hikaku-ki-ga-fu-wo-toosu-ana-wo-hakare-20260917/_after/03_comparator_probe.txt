# 03 比較器 単体 ―― 生器 L58 逐語:
#   num_same_op() { [ "${1:-}" -ge 0 ] 2>/dev/null; [ $? -le 1 ]; }
# bash=GNU bash, version 3.2.57(1)-release (arm64-apple-darwin25)
# 「通」= num_same_op が真 = 既定 10 へ倒さず ★其の値のまま read -t へ渡す★

## 陰性(守る筈 = 通つてよい)
10            	内 [ v -ge 0 ] rc=0	比較器 出目=通
0             	内 [ v -ge 0 ] rc=0	比較器 出目=通
既定(未設定)   \t―― 比較器へ届かぬ: L64 の ${VAR:-10} が 10 に解く ∴ 実質 10 と同じ

## 陽性(開く筈 = 止まるべきが通つてゐないか)
-5            	内 [ v -ge 0 ] rc=1	比較器 出目=通
-1            	内 [ v -ge 0 ] rc=1	比較器 出目=通

## 境

010           	内 [ v -ge 0 ] rc=0	比較器 出目=通
2^63超(20桁)	内 [ v -ge 0 ] rc=2	比較器 出目=止
