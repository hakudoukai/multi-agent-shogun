## 二 ★己の疵★ ―― 番人が、番をして居た旗を食つた

`~/bin/km_send.sh` は「`letter` の後の位置引数が 1 でなければ送らずに落ちる」門として
當席が建てた**私器**である(送り器の argv の罠を★六度★踏んだ故)。
其の検め輪が斯う書かれて居た:

```sh
while [ $# -gt 0 ]; do
  case "$1" in
    --to|--parent-seq) shift 2 ...; continue;;
    --*) shift; continue;;
    *) n=$((n+1)); ...; shift; continue;;
  esac
done
exec "$HOME/bin/sb-karo-mac" write letter "$body" "$@"   # ← "$@" は★既に空★
```

`while`+`shift` が `"$@"` を**食ひ尽くす**。∴ `exec` へ旗が**一つも渡らぬ**。

**何故 見えなかつたか**: 宛先の既定が `iincho` と**一致して居た**故、
便は正しく届き・rc=0・seq も出た。**落ちたのは `parent_seq` だけ**であり、
送出行にも出目にも何も現れなかつた。**讀み返し(第八の番人)だけが捕へた。**

### 直し

- 検めを `for a in "$@"` へ替へた(`for` は `shift` せぬ＝消費せぬ)。
- 値を取る旗は「直前が旗なら次を飛ばす」形で追ひ、**末尾の旗が値を欠く**場合も rc=2 で落とす。
- **渡す argv を stderr へ刷る**ようにした ―― 旗が食はれて居らぬ事を目で検められる。
- `KM_SEND_DRYRUN=1` で**送らずに argv だけ刷る**空走を足した(之が対照を可能にする)。

## 三 此の疵の教へ

★番人を建てても、番人が己の検める物を壊して居らぬかは**別に測らねば判らぬ**。★
六度の疵を塞ぐ器を建て、其の器が七度目の疵を作つた。
形は違ふ ―― 六度は「胴が消える」、七度は「旗が消える」。
**両方とも rc=0 で、出目には何も出ぬ。**

∴ 送り器の対照は「**送つた後に讀み返す**」だけでは足らず、
「**送る前に渡す argv を刷る**」を併せねば、旗の落ちは捕へられぬ。
