## 二. ★裁の文言に一箇所 効かぬ所が在つた（上申）★

裁⑴ は「全 read に timeout(10s)を付け」と申された。**門の該当箇所の形では効かぬ。**

- 實測（家老mac・本日）: `timeout 3 wc -c < "$fifo"` は **120 秒 戻らなんだ**（背へ回して止めた）。
- 因: `<` 再向は **shell が open() する**。∴ `timeout` が exec される **前に** 止まる。時限は起動すらせぬ。
- 効く形は二つ: ㋐ path を **引数** で渡す（`timeout N wc -c "$f"`。但し `wc` は出目に file 名を混ぜる） ㋑ **開かぬ**（`stat -f %z`）。
- ∴ 門は ㋑ を採つた ―― **「時限を付ける」でなく「開かぬ」が本筋**。hook 側は fd が既に開いて居る故、裁の文言通り時限が効く（採用）。
- **上へ: 裁の処方は `cmd < "$f"` の形には当たらぬ。argv 形か、開かぬ形へ改められたい。**
