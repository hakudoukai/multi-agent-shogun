## ㋒ 「空 = 既定1 = 処理する」は fail-closed か fail-open か

### ★語では「fail-closed」と謂ふ。出目は其れを支へぬ。★

`fix_flag` は空・空白へ倒す時 ★「fail-closed」と自称して刷る★。然し出目を見よ:

- 空(`''`) の pu_timeout = **3** ―― 之は `'0'` の **0** ではなく、`'1'` の **3** と同じである。
- 空白(`' '`) も同じく **3**。
- ∴ ★倒れた先は「何もせぬ側」ではなく「働く側」である。★

「fail-closed」を **「危ない事をせぬ側へ倒す」** の意で読むなら、★本件は fail-closed ではない★。

### 但し ―― 「危ない」が二軸ある。★一語で断ずるのが誤りである。★

| 軸 | 何が起きるか | 既定1 は | 名 |
|---|---|---|---|
| 甲 **取りこぼし** | fswatch が事象を落とすと、未読が永久に箱へ残る。刻限 tick は其の安全網 | 網を**張る** | 甲では **fail-closed** |
| 乙 **過剰動作** | 刻限ごとに突つき、無応答が続けば Phase3 で `/clear` ―― ★文脈を消す★ | 網へ**踏み込む** | 乙では **fail-open** |

∴ 正しい書き方は ★「取りこぼしに対して fail-closed、過剰動作に対して fail-open」★。
`fix_flag` の刷る「fail-closed」は ★軸を言はぬ★ 分だけ、読む者を甲の側へ寄せる。
