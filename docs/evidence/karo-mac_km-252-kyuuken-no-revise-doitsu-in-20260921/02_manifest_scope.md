# 02 ―― 臺帳の名と範囲（★家老mac が名と除外を宣す★）

## 臺帳の名

`manifest.txt`（束内相対・裁 seq322699「臺帳の根は束内相対」）。

**★何故 名を宣すか★** ―― 過去の束で臺帳の名が四形（`MANIFEST.txt` / `manifest.txt` /
`_manifest.txt` / `_hosoku/_manifest.txt`）に分かれ、四形とも門を通つた。
**因は器ではなく「家老mac が名を宣さなかつた事」であつた。** ∴ 本束では名を本紙で宣す。

## 載せる物（母數の式）

```
束 disk 全 file            = N
− 臺帳自身 manifest.txt     = 1
− 臺帳/門の札 9[0-9]_*      = M
= 臺帳の path 行            = N − 1 − M
```

**本束の値は納便で宣す**（本紙を書いた刻には門が未走ゆゑ M が確定せぬ）。

## 除く物と其の理由

| 除く物 | 理由 |
|---|---|
| `manifest.txt` | 臺帳は己の sha256 を書けぬ（自己言及） |
| `9[0-9]_*`（`90_manifest_append.out/.err`・門の札） | **臺帳を建てた後に生れる** ―― 順が「紙→臺帳→門→commit」ゆゑ構造的に載らぬ |

**★除いた物も母數には数へる★**（宣した除外は分母から消えぬ）。
∴ 納便では「束 disk 枚数」と「臺帳 path 行」の両方を書き、差が除外分と一致する事を示す。

## 順（裁 321856・321353 に従ふ）

1. 紙を確定する（本紙 01・02・80_raw/*）
2. 臺帳を `karo_mac_manifest_append.py` で**建て直す**（手書き行 0）
3. 門を走らせる（札は 9[0-9]_*）
4. commit する（`git add -f` 名指し ＋ `git commit --only`・`reset` は打たぬ）
