# ★臺帳に載せ得ぬ物の宣★ ―― 家老mac 検分便 km-83 ⑷ を作法として受けた
# 逐語:「★載せ得ぬ物が在る事には宣が要る★(「臺帳に載せ得ぬ N 本」を紙へ一行)。次弾以降の作法とせよ。」

【何故 此の宣が要るか】
  行單位の臺帳は path= 行を一行で表す。
  名に改行を持つ file は ★path= 行が途中で切れる★ 故、書き手が拒むか否かに拘らず
  ★構造上 載せられぬ★。symlink・FIFO・socket も同様に「規定fileでない」故に載らぬ。
  是等は取り零しではなく ★臺帳といふ形式の外に在る物★ である。
  ∴ 「載らなかつた」ではなく「★載せ得ぬ★」として、零であつても数を宣する。

【km-87 の実測】
  歩いた規定file(S_ISREG)              = 184 本
  ★載せ得ぬ 改行/引用符を名に持つ file = 0 本★
  ★載せ得ぬ symlink                    = 0 本★
  ★載せ得ぬ 非規定file(FIFO/socket等)   = 0 本★
  ―――
  ★載せ得ぬ 計 = 0 本★

【数の突合せ(184 を余さず割る)】
  184 = 147(臺帳 path行) + 1(臺帳自身 MANIFEST.txt ―― 己を数へられぬ) + 36(門 r4 の後に生れた残留)
  残留 36 の名は悉く _gate/80_mongo_zanryuu.txt に在り。
  ∴ ★184 本 一本も行方知れずに成つて居らぬ。★

  證拠の束に生きた FIFO を残せば、此の紙が documented する其の地雷を
  ★証拠の中へ埋める★ 事に成る故である(除去と権000→644 の戻しは ㋕ に宣済)。
  其の結果として「非規定file = 0」が成つて居るのであり、初めから無かつたのではない。
