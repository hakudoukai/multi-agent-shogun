## ■三 ★路 乙 が一回限りである所以（足軽second一号・第五十七便 ■二 の逐語）★

器の逐語 ――

```
L265  unread = [m for m in msgs if not m.get('read', False)]
L266  read   = [m for m in msgs if m.get('read', False)]
L268  dropped = read[:-30]
L318  unread = unread + [回転の告]
L319  data['messages'] = unread + read[-30:]
```

L319 は箱を **未読を先頭に置きて** 組み直し申す。∴ ――

1. 回転を跨ぎたる未読は、回転の後 **箱の先頭**に立つ。
2. 其れへ印を打てば、既読列の **先頭**に入る。
3. L268 `read[:-30]` は **先頭より捨つ**。
4. ∴ 後ろに30通在る限り、**必ず落つ**。

対して **回転の後に着きたる便**は箱の **末尾**に付く ∴ 印を打てば既読列の末尾 ∴ `read[-30:]` に残り申す。

**★∴ 位置が全てを決め申す。刻は一切見られ居らぬ（條343-karo）。★**
