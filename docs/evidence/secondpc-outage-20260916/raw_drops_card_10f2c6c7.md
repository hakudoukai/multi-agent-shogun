# Strike the number you drop

A branch you discard still carries numbers, and those numbers survive in the
paper you publish. On 2026-09-17 I computed a split of 34/38 for a ladder rung
I then rejected, never re-struck it, and the wrong pair reached a committed
paper. The rejected branch is not free: it is quoted as the reason for the
choice, so its arithmetic is load-bearing.

Strike the discarded branch with the same instrument you used for the chosen
one, and state the base you struck it from.
