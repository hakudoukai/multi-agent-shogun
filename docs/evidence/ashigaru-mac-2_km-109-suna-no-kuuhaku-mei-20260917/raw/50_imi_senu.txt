# ㋕ 此の弾の數が ★意味せぬ★ 事

一、★「偽の通 N 件」は「器が健かである」の意ではない。★
    當席が數へたのは ★己が作つた五條の出目★ と ★repo 内の臺帳に在る行の形★ である。
    「偽の通が現に出たか」は ★臺帳の行と disk の中身が偶々合ふか★ に懸かる。
    ㋓ が乙(真の空白名)を何行と出さうと、其の行が指す先頭語が disk に在るか・
    在つたとして中身が合ふかは ★測つて居らぬ★。∴ ㋓の數は ★偽の通の上限でも下限でもない★。

二、★㋒ の rc=0 は「五條の内二條で出た」であつて「二割の確率で出る」ではない。★
    五條は當席が ★偽の通が出る側へ寄せて作つた★ 標本である(c2/c4 は其の為に足した)。
    現物の臺帳から取つた標本ではない。∴ ★割合として讀むな。★
    此の五條が言ふのは ★「出得るか」への可否★ 丈である ―― 可否は閉ぢた。廣さは閉ぢて居らぬ。

三、★㋑ の「則②が当たつた 4/14」は器の性であつて、臺帳の實勢ではない。★
    綴りは當席が選んだ。★選び方が數を決める。★ 14 の母數に重みは無い。

四、★㋓ の disk 欄と樹 欄は ★同じ物を二度數へた★ のではない。★
    樹(origin/main 534本 / HEAD 1291本)に在る紙は disk 45,979本の ★一部に過ぎぬ★。
    repo の .gitignore は allowlist 形(一行目近くに裸の `*`)ゆゑ、
    束の紙の大半は ★樹に無い★。∴ 樹 欄が 0 でも disk 欄が 0 とは限らぬ。逆も然り。

五、★「乙(狭)」は「名に空白が在る」の證ではない ―― ★疑へる★ に過ぎぬ。★
    行だけを見て「名に空白が在るか」は ★決められぬ★。之が本件の核である。
    決められぬ物を數へた故、乙は ★上限側の見積り★ と讀め。
    (逆に甲は bytes= が間に挟まる行を含む故、★空白名の數としては過大★。)

六、★「rc=0」は「照合が為された」の意ではない。★
    ㋒ c2 が示した通り、★臺帳が名指した file が disk に一本も無くとも rc=0 が出る★。
    rc は「當てた物が合つた」を言ふのみで、「★當てた物が、臺帳が名指した物であつた★」は言はぬ。

七、★當席の束の中の試験臺帳(5本)は現物の害ではない。★
    ㋓の disk 欄から別欄へ分けたが、★歩いて居らぬのではなく 歩いた上で分けた★。
    若し誰かが後日 repo 全体を數へれば、當席の 5 本は ★乙に数へられる★。
