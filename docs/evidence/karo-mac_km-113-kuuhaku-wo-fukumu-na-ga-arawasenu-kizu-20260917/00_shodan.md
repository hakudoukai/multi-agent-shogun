## 一 ★疵の正体★ ―― 直しは既に在つたが、己が書かれた当の場合に限つて到達不能であつた

`scripts/checks/karo_mac_manifest_verify.py` の `paths_of()` は、
臺帳の一行から path の候補を取り出す。旧はかう書かれて居た:

```python
m = re.search(r'(?:^|\s)path=([^\s"\']+)', line)        # ①本形
if not m:
    m = re.search(r"(?:^|\s)path=(.+?)[ \t]+sha256=", line)  # ②非貪欲(素の空白名)
if not m:
    m = re.search(r"(?:^|\s)path=(\S+)", line)           # ③従来形
if m:
    out.append(_dequote(m.group(1)))
```

則② は **2026-09-12 の止血**(総監督裁 seq307881/307874 ⑵)が
**★空白を含む名の為に★** 足した則である。器自身の註が逐語でさう述べて居る:

> 旧版は ``path=(\S+)`` の一本しか持たず、★名に空白が在ると其處で切り落した★。

**然るに則②は `if not m` の連鎖の二番目に置かれた。**
そして **★則① は空白を含む名にも必ず當る★** ―― `[^\s"\']+` は空白の手前で止まる故、
`path=c d.txt sha256=…` から **`c`** を捕つて **成功する**。
`if not m` は偽に成り、**則②は決して試されぬ**。

> ### ★空白名の為に書かれた則が、空白名の時だけ死んで居た。★

**實測**(`raw/20_dore_no_nori_ga_katsu_ka.txt` ―― 則の字面は器から逐語で抜いた。手打ちに非ず):

| 見本 | 則①本形 | 則②非貪欲 | 則③従来形 | 旧の連鎖が採る物 |
|---|---|---|---|---|
| `path=c d.txt …` | ★當る `'c'`★ | 當る `'c d.txt'` | 當る `'c'` | **★則①の `'c'` ―― 以下は試されぬ★** |
| `path="e.txt" …` | 當らず | 當る `'"e.txt"'` | 當る `'"e.txt"'` | 則②の `'"e.txt"'` |
| `path=kiyoi.txt …` | 當る | 當る | 當る | 則①(正しい) |

## 二 ★何故 括つて逃げられぬか★ ―― 之が「表せぬ」の意

- **括れば禁に触れる**: 裁 seq321353⑵ 「臺帳へ ★新規に書く行では引用符を用ゐぬ★」。
- **括らねば鳴る**: 則①が空白で切り落す。

∴ 空白を含む名は **臺帳の上で表す術が無かつた**。
之は書き手の落度ではなく **★器の疵★** である。

## 三 ★直しの形★ ―― 順を入れ替へず、悉くを候補として列ねる

```python
for _pat in (則①, 則②, 則③):
    m = re.search(_pat, line)
    if m:
        _t = _dequote(m.group(1))
        if _t and _t not in out:
            out.append(_t)
```

**★何故之が安全か★** ―― `paths_of` は **候補の列** を返し、使ひ手は其れを順に disk へ問ひ、
**在る物だけを昇らせる**(器の L135 以降 `for p in cands: … if os.path.isfile(cand)`)。

- 則①の正しい出目は **先頭に居る儘** ゆゑ **★決して奪はれぬ★**。
- 則②③が生む偽の候補(例: `path=a.txt bytes=4 sha256=…` から則②が捕る `a.txt bytes=4`)は、
  **disk に無ければ黙つて落ちる**。
- ∴ **順の入れ替へを一切要せぬ**。之が「候補を足す」直しを安全にして居る性質である。

**★順を入れ替へる直しは採らなかつた★**。則②を先頭へ置けば、
sha256 が path の直後に無い方言(`path=a.txt bytes=4 lines=1 sha256=…`)で
**`a.txt bytes=4 lines=1` を捕つて仕舞ふ**からである。

## 八 ★此の紙の數が意味せぬ事★(數の規律)

1. **「rc=0 に成つた」は「臺帳が正しい」の意ではない** ―― 照合器が path を正しく捕る様に成つただけ。
2. **「四版」は版の全てではない** ―― git に在る他の版は歩いて居らぬ。測つたのは此の四本。
3. **「km-105 実束 rc=0」は km-105 の監査が通つた意ではない** ―― 條①(臺帳照合)一つの出目に過ぎぬ。
4. **走つて居る席の器は此の瞬間に変らぬ** ―― 共有 worktree に触れて居らぬ故。
   着地して各席が引いた時に初めて変る。
