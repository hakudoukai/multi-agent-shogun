## 五、★止め甲★ ―― 紙の直しが UTF-8 を壊す

```

```

BSD `tr` は ★byte 器★ である。`\266` は 1 byte `0xB6` であつて、`¶`(U+00B6 = UTF-8 で 2 byte `C2 B6`)ではない。
∴ 札に ★UTF-8 として不正な byte★ が入る。

★實測★: 當席の器が札を `text=True` で受けた初走が `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xb6` で倒れた。
