第49弾 則 ―― ★測る前に宣す★(器を一本も走らせて居らぬ刻に書いた)

書いた刻 = 00_koku.txt(2026-09-17T02:56:46)。本紙より後に建つ器は一本も無い。

────────────────────────────────────────
一 ★部材とは何か★(札 ㋐ ―― 四つの候補から一つを選ぶ)
────────────────────────────────────────

  ★選ぶ = 一本の file(= disk 上の常なる file 一個)★

  選んだ理由(三つ):
  ⑴ ★分割である★ ―― 束の全 file は「一本」に一度づつ属す。∴ 排他であり、
     部材の和 = 束の和 が ★恒に★ 成り立つ。重複も漏れも構造上起き得ぬ。
     (dir も拡張子も群も、属し方が一意でない場合が在る ―― 下記)
  ⑵ ★開かずに測れる★ ―― 寸法は stat で取れる。中身を讀まぬ ∴ FIFO/device/
     壊れた多byte字に ★止められぬ★(門が第三の出目「止」で死ぬ事が無い)。
  ⑶ ★名指せる★ ―― 鳴つた時に出るのは path 一本。束級の閾は「束が重い」としか
     言はぬ。第48弾で席が書いた「誰が重いかを言はぬ」の直の答が之である。

  選ばなかつた物と其の理由:
  ・★一つの dir★ ―― 入れ子ゆゑ ★一本が幾つもの dir に属す★(a/b/c.txt は a にも a/b にも)。
    和を取れば二重に数へる。除けば「どの段で数へるか」を別に決めねばならぬ。
    加へて束の形に依つて出目が変る(平らな束では束級と同じ數に潰れる)。
  ・★一つの拡張子★ ―― 名の飾りであつて ★中身の保證が無い★。`.txt` が 2MB でも
    `.tsv` が 3 byte でも拡張子は同じ顔をする。且つ ★誰が重いかを言はぬ★(群の和しか出ぬ)。
    名に `.` が無い物・二重拡張子(`.tsv.json`)の扱ひが一意に決まらぬ。
  ・★同内容の群(重複)★ ―― ★之は部材級の閾の仕事ではない★。
    群を括るには ★全部の中身を讀んで sha を取らねばならぬ★(開く ∴「止」の危険)。
    且つ sha 一致は ★一字違へば別の群★ に成る ―― 第48弾で落とした三本は
    2,632,943 / 2,634,088 / 2,632,945 と ★寸法が違ふ★ ∴ sha も違ふ。
    ∴ 重複級の閾は本弾の的(7,896,856)を ★取り逃がす筈である★(予言三)。
    但し ★測らずに捨てぬ★ ―― 四つとも同じ束で數を出し、表で並べる(30_hikaku)。

────────────────────────────────────────
二 ★閾の値と其の由来★(裁294493⑸「固定値を焼き込むな」に従ふ)
────────────────────────────────────────

  部材級の閾 = ★1,048,576 byte(= 1 MiB)★ = 束級の閾 10,485,760 の ★1/10★。

  由来:
  ⑴ 束級の閾は 10,485,760 = 10 × 1,048,576 ―― ★既に 1 MiB の十倍として建つて居る★。
     ∴ 部材級を 1 MiB に置くのは新しい數を持ち込む事ではない。
  ⑵ 意味 = 「★一本で束の十分の一を占める部材は、束級の閾が黙つて居ても
     束の性質を一本で決めて居る★」。之は寸法の問題ではなく ★代表性★ の問題である。
  ⑶ ★不感帯を先に宣す★ ―― 第48弾の紙に依れば、束の中で 10 万 byte を超える部材は
     四本(最小 2,632,943)、其の直下は 91,479 である。∴ 閾を 91,480〜2,632,943 の
     何處に置いても ★本束では同じ四本が出る★。1,048,576 は其の帯の中の
     ★由来の在る一点★ であつて、四本を出す為に選んだ値ではない。
     (帯の広さ = 2,632,943 / 91,479 = 約 28.8 倍。刃の上に立つて居らぬ)
  ⑷ 閾は env `BUZAI_MAX_BYTES` で動く。非數なら ★既定へ倒し、倒した事を言ふ★
     (黙つて倒すのは別の fail-open ―― 生器 L46-49 の法に同じ)。
  ⑸ 比べは ★-ge(閾丁度で鳴る)★ ―― 生器の條⑤ `[ "$total" -ge "$MAXB" ]` と同じ向きに揃へる。

────────────────────────────────────────
三 ★予言★(測る前に書く ―― 外れたら外れた儘 残す)
────────────────────────────────────────

  予言一: 部材級(一本・閾 1 MiB)は第47弾の束で ★4 本★ を名指す。
  予言二: 其の四本の和は 10,532,919 であり ★7,896,856 とは一致せぬ★。
          ∴ 部材級の閾は 7,896,856 を ★見せぬ★(名指す物の中に含むが、其の數は出さぬ)。
  予言三: 同内容の群(sha 一致)で括れば重複は ★一組(2,632,943)★ に留まり、
          7,896,856 には ★届かぬ★。
  予言四: 拡張子級(.tsv)は四本を一群に纏めて和 10,532,919 を出すが ★誰が重いかを言はぬ★。
  予言五: dir 級は第47弾の束が ★raw/ 一段で平ら★ ゆゑ ★束級と同じ數に潰れる★。
  予言六: 非數の閾 六形の内 ★零(0)だけは is_num を通る★。∴ 零は既定へ倒れず、
          門は ★恒真(何もかも鳴る)★ に成る。之は fail-open ではなく ★恒真の穴★ である。

────────────────────────────────────────
四 ★何を以て「器である」とするか★(恒真でない證の建て方)
────────────────────────────────────────

  陽性(鳴るべき束)三形・陰性(鳴らぬべき束)三形を ★先に決めて★ から走らせる。
  陰性の境は ★勘で選ばぬ★ ―― 閾の直下(閾−1)・閾丁度・閾+1 を器自身に作らせる
  (第48弾 ㋖-2「汚し所を勘で選び差に呑まれた」の直し)。
  ★陰性が一形でも鳴れば其れは器でなく騒音である。★ 落ちた走は消さずに残す。
