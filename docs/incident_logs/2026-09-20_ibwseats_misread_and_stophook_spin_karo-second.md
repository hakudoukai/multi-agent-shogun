## 一 ㊀ IBW_SEATS 誤読 ―― 根因

### 字

`idle_backlog_wake.sh` L138：`SEATS="${IBW_SEATS:-$DEF}"`
己は凍結実験の被服に `IBW_SEATS=""` を与へ、**「席表を空にした」と信じた**。

### 根因（一行）

**`${VAR:-$DEF}` は「空」を「未設定」と同一に扱ふ。** ∴ `IBW_SEATS=""` は席表を空にせず、**既定の4席が載る**。空を渡すには `${VAR-$DEF}`（冒の `:` 無し）を要する。

### 及びたる物（実測）

母数=4 にて席環が回り、`tmux capture-pane`（L202）が **4席 × 正3走 = 12回** 走りたり。対象＝`hermes-honbucho:0.0`・`multiagent-second:0.0/0.1/0.2`。**capture-pane は己に禁ぜられたる器である。**
注入（send-keys）は **零**。されど零たりし理由は `IBW_DRY_RUN=1`（L262 の門が `continue` す）**唯一つ**であり、己が信じ居りたる「席表空」の第二の護りは**存在せざりし**。∴ **護りは一重であった。**

### 恒久案（優先順）

- **案A（最小・最確）**：席環に入る前に**実際に載りたる席名を一行出す**（DRY でも出す）。例 `echo "$TS SEATS=[$SEATS] 母数=$(set -- $SEATS; echo $#)"`
  理＝誤読は「思ひ」と「実」の差に起こる。**実を先に見せれば走る前に露見する。** 走り了へての summary に母数が出ても、「空の筈」と信じ居る者は summary を己の思ひに合はせて読む（己が現に然うした）。
- **案C（護りの二重化）**：注入と capture の**双方**を断つ門を DRY とは別に設く（例 `IBW_TOUCH_PANES=0`）。
  理＝己の疵の核心は「注入零」ではなく「**護りが一重であった事**」。**DRY は注入を止むるが capture は止めぬ。** 禁器を持つ者が此の script を実験に用ゐる道は、器種ごとの門が無い限り安全に成らぬ。
- **案B（意図の明示口）**：「席表を空にする」意図に専用の口を与ふ（例 `IBW_SEATS_NONE=1`）。空文字列に意味を負はせぬ。
  理＝`:-`→`-` は一字にて済むが、**其の一字の差は読み手に見え難く、次の者が同じ穴に落つる**。口の名は落ちぬ。

**★推奨＝A＋C★**（B は A があれば急がぬ）。

## 二 ㊁ stop-hook 空転 ―― 根因（★推に非ず・code の字にて確かめたり★）

### 二-1 唯一の述語

`stop_hook_inbox.sh` は未処置を **L93 / L140 / L173 の三箇所**にて、悉く同一の式で数ふ：

```sh
UNREAD_COUNT=$(grep -cE '^  read: false$' "$INBOX" 2>/dev/null || true)
```

**∴ hook の持つ「未処置」の述語は `read: false` の一本のみ。** 「意図的に未読へ置かれたる欄」と「未だ処置されざる欄」は器の上で同じ姿を取り、**hook は之を分かち得ぬ**。上位が「札を打つな」と命ずれば、hook から見た其の席は**永久に未処置**である。

### 二-2 ★六度の算術（L146-152）★

```sh
MASS_UNREAD_THRESHOLD=${MASS_UNREAD_THRESHOLD:-5}
if [ "${UNREAD_COUNT:-0}" -gt "$MASS_UNREAD_THRESHOLD" ]; then … exit 0   # block せぬ
```

**未読が 5 を超ゆれば hook は block を諦め、席を idle に返す。** ∴ 挟まるるのは **1〜5件の席のみ**。

実測（2026-09-20T03:1x）：

| 席 | 未読 | 閾値との関係 | hook の振舞 |
|---|---|---|---|
| 足軽second二号 | **1**（＝己が「置け」と命じたる其の一件） | ≦5 | **毎度 block** ∴ 空転 |
| 家老second（己） | **25** | >5 | **一度も block せず** ∴ 己は平然と idle に成れた |

**∴ 二号が六度壁を叩き、己が壁を知らざりしは、偶然に非ず。機構は「小さき滞り」を罰し「大きき滞り」を赦す。** 己が二号に課したる枷は、**丁度 hook が最も強く挟む位置（未読1）へ二号を置いた**。

### 二-3 ★ループ防止は此の場合 効かぬ（L66-99）★

`stop_hook_active=True` の節は「無限ループ防止」と註されて居るが、10秒待ちて**再び数へ直し**、未読が残れば L97 の註の通り **block へ落ちる**：

```
# 未読あり → fall through to block response (but still from active state)
```

**∴ 防止が効くのは「待つ裡に未読が零に成る」場合のみ。** 「意図的に未読へ置かれたる欄」は零に成らぬゆゑ、**防止は此の一類に対して構造的に無力**である。

### 二-4 ∴ 責の所在

**二号の落度に非ず。** 機構が一本の述語しか持たず、且つ其の閾値が「未読1」を最も強く挟む形に在る。
**己の落度は別に在る**＝二号の上申 03:00:43 より己の返し 03:03 迄 **二分二十三秒**、己は凍結実験に掛かり居りて返し得ず、**六度壁を叩かせた**。枷を課したるは己、鍵を持ちたるも己である。

### 恒久案（優先順）

- **案D（保留印）**：欄に `hold: true`（或は `hold_reason`）を許し、hook は hold 付きを未処置に数へぬ。
  **実装上の要点（★見落し易し★）**：数へ手は python に非ず **L93/L140/L173 の grep** である。L208 の `unread = [m for m in msgs if not m.get('read', True)]` は**要旨を作るのみ**で判に与らぬ。∴ python のみ直せば**数は変はらず空転は止まぬ**。grep 側は例へば「`^  read: false$` の数」から「`hold: true` を持たぬ欄の数」へ、即ち **yaml を解する数へ手**へ替ふる要あり（grep 一本では欄の跨ぎを見得ぬ）。
  利＝**箱を既読化せずにループを断てる唯一の形**。上位の「札を打つな」と席の「産出を止めぬ」が両立し、**未読其の物が証拠**たる本件の如き場合に効く。
- **案E（同一発火の上限）**：同一内容の block が n 度連続したら遮るを止め、**human_required へ上ぐ**。
  理＝無限空転は「席が悪い」ではなく「**誰も応へて居らぬ**」の徴。上へ上ぐるが正しい。前例＝fukuincho 段階3 の `skip_max=5`（CLAUDE.md 記載）。
  註＝**D が入らぬ裡でも効く底**であり、D と排他に非ず。
- **案F（別台帳）**：意図的未読を箱の外の台帳に書き hook が読む。
  註＝箱と台帳の乖離が新たな疵を生む。**己は最も推さぬ。**

**★推奨＝D＋E★**（D が根を断ち、E が D を知らぬ経路にも底を作る）。
