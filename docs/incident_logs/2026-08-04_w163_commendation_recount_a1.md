## §3. 「止まった」と「何もせなんだ」を見分ける形(設計・本工区の眼目)

現行の台帳は「したこと」を記録する構造であり、「しなかったこと」は記録が存在しない=空白として現れる。空白は「怠けて何もしなかった」のか「正しく判断して止まった」のかを区別できない。以下の形を提案する(裁定ではなく設計案としての提示)。

**必須4フィールド化(全ての報告テンプレートへ追加)**:
1. `行為種別`: 実行 / 不実行-申告(自己申告) / 不実行-指摘(他者指摘で判明) / 不明
2. `理由の明記`: Y/N — Yなら理由を1行で引用
3. `申告主体`: 本人 / 他者 / 不明
4. `為し得た代替行動`: 自由記述。★`行為種別`が不実行-*の場合は必須(空欄提出禁止)★

**判定ルール(機械的に適用可能)**:
- 行為種別=不実行-申告 かつ 理由の明記=Y → 褒(P3)候補
- 行為種別=不実行-指摘 かつ 理由の明記=N → 落度候補(黙って狭めた/怠けた型)
- 行為種別=不明(理由も申告主体も無い、すなわち台帳に一切記載が無い) → **判定不能として明示的に1行を立てる**。従来はこの状態が「行が存在しない」=完全な空白になっていたが、これを「判定不能」という★可視の第四状態★として台帳に必ず1行起こすことで、「何もせなんだ者」と「記録されなかっただけの者」を区別できるようにする。

**実施方法**: 各lane(a1〜a7・karo-second)の日次ETA/report提出テンプレートに上記4フィールドを追加し、`為し得た代替行動`欄が真に空(該当なし、の記述すら無い)の提出物は、他の必須欄(母集団宣言・健全例)と同様に★提出未完扱いとして差し戻す★機構的強制を設ける(軍師second監査時のチェック項目へ追加、を提案。裁定・実装はしない)。

**当職自身の『為し得たのに為さなんだか』(1行、要件★当職の褒★対応)**: 本工区で、落度41全件(pruned archive分含む13〜24番台)を同一手順で精査することは、ETAを延ばせば為し得たが、17:40の確定ETAを優先し「主受信箱3つ・番号明示分のみ」に範囲を絞り、その限定を§0で明記する道を選んだ。網羅よりも期限内提出を選んだ、という選択である。
